# Property access & security SOP

Customers may entrust keys, lockbox details, garage codes, smart-lock codes and alarm
information. That information is confidential and is handled with least access.

## Principles

1. **Least access** — receive only what the booked work requires. No alarm panel codes unless
   leaving the home requires arming/disarming; no garage code if a door code suffices.
2. **Least retention** — keep access details only while the customer relationship is active.
   Remove them when service ends or the customer asks.
3. **Confidentiality** — access details are never written into public systems: no analytics, no
   shared notes, no group chats, no screenshots, no email threads that don't need them.
4. **Never use access outside booked work.** Ever. No exceptions.
5. **Rotation on change** — when a customer changes codes, delete the old value immediately.

## Where access details may live

| Location | Allowed? |
| --- | --- |
| Owner's password-protected device / booking records | Yes |
| Printed at the job site | Only temporarily, then destroyed |
| Text message with the customer | Yes (their choice of channel) |
| Analytics/events, marketing docs, public repos, shared photo albums | **Never** |

The website never receives or stores access codes: no form field collects them, and the lead
function would reject them as out-of-policy if one were entered in free text. If a customer
puts a code in a message, move it to the secure record and remove it from the message where
possible.

## Day-of-work checklist

- Confirm the access method before arrival (code valid? lockbox present?).
- If access fails: wait a reasonable period, contact the customer, and treat no-access per the
  cancellation policy (same-day/no-access terms).
- Do not force entry. Do not enter if a pet is unsecured and unsafe (see the aggressive-pet
  FAQ) or if occupancy is unexpected.
- Lock up exactly as instructed; confirm the home is secured before leaving.
- Report anything unusual (unlocked door, damage, alarm events) to the customer promptly.

## Alarm events

- If the alarm triggers: identify yourself to the monitoring company if they call, contact the
  customer immediately, and follow their instruction.
- Never guess at alarm codes; if arming requires a code the customer has not shared, skip arming
  and tell them.

## Review cadence

- After every service ends: delete access details.
- Monthly: scan stored notes for stale codes and remove them.
