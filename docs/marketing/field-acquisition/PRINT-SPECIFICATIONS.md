# Print specifications — production suite

Generated by `npm run print:build` from `scripts/print/manifest.mjs`. Facts are verified against
`src/config/business.ts` / `src/config/brand.ts`; QR destinations resolve through
`src/config/marketing-links.ts`. The live copy of this document is written to
`Specifications/PRINT-SPECIFICATIONS.md` in the output root.

## Global rules

- Bleed 0.125 in on all sides; `*-bleed.pdf` carries corner crop marks outside the trim and a real
  TrimBox/BleedBox. Use `*-trim.pdf` with online printers that supply their own bleed template.
- PNG previews are 300 DPI at trim size (foam board preview 150 DPI).
- Fonts are embedded in the PDFs; HTML sources reference the repository WOFF2 files.
- Champagne/gold is an accent only; no small light-on-cream gold text.
- Door hanger: 1.25 in hole centered 0.925 in from the top; printable artwork keeps content ≥0.25 in
  below the hole. `Specifications/door-hanger-die-guide.pdf` is a placement guide — **never print it**.
- QR: dark on white, 4-module quiet zone; minimum 0.85 in on cards; every QR decodes to its registry
  URL (verified).

## Workflow

1. `npm run print:build` — generate all variants into the output root.
2. `npm run print:verify` — must pass before anything is printed.
3. Proof one physical copy per piece and compare against the PNG previews.
4. Reorder from the same verified PDFs; rebuild only when facts/brand change.

## Printer notes

- Request one proof before the full run. Compare against `PNG-Previews/`.
- Use `Print-Ready-PDF/<variant>/*-bleed.pdf` for local shops; `*-trim.pdf` for online printers.
- Colors are RGB; ask the shop to convert to CMYK and match the website.
- Never let a printer redesign the logo or retype the phone number.
