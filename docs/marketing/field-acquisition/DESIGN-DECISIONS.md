# Design decisions — Stage 2 physical acquisition system

Owner-approved Stage 2 implementation. Source of truth for the creative system:
`scripts/print/manifest.mjs` (pieces, variants, production mix), `src/config/brand.ts`
(mark/wordmark/palette), `src/config/business.ts` (facts), `src/config/marketing-links.ts` (QR).

## One brand, three variants

| Variant id | Label | Role |
| --- | --- | --- |
| `neighbor` | From a Neighbor | Warm, founder-led pieces for door-to-door and neighborhood contact |
| `utility` | The Detail Standard | Structured, scannable pieces for QR/utility and professional desks |
| `editorial` | The Standard | Premium editorial pieces for large-format and community presence |

All 27 sides (9 sides × 3 variants) are generated by `scripts/print/print-system.mjs`. Every variant
shares the crest, wordmark, fonts, palette, verified facts and registry QRs; they differ in
composition, hierarchy, information flow and imagery.

## Recommended production mix (owner delegated the direction choice)

| Piece | Recommended | Why |
| --- | --- | --- |
| Business card | From a Neighbor | Most personal hand-off; portrait + first-person note |
| Quarter sheet | From a Neighbor | Neighborhood handout; letter-like note converts |
| Door hanger | From a Neighbor | Porch greeting from a real local owner |
| QR estimate card | The Detail Standard | Exists to be scanned; clearest 3-step hierarchy |
| Event poster | The Standard | Large-format presence benefits from editorial restraint |
| Foam board | The Standard | Booth board must read at distance |
| Community leave-behind | From a Neighbor | Keep-on-desk hospitality fits community spaces |
| Realtor referral card | The Detail Standard | Professional desk card; move-out clarity |

The mix is recorded in `PRODUCTION_MIX` in `scripts/print/manifest.mjs`; every piece still exists in
all three variants.

## Print-service-area wording (owner delegated)

- **Large format** (poster, foam board, community leave-behind): the exact approved sentence —
  “Serving Pensacola, Cantonment and surrounding communities within about an hour of Cantonment, with
  select nearby service into Alabama.”
- **Small pieces** (cards, sheets, hanger, QR card): the same sentence with the qualifier removed —
  “Serving Pensacola, Cantonment and surrounding communities, with select nearby service into
  Alabama.”

Why: the full sentence is the verified website wording; the short form is a verbatim subset (no
geography added, widened or invented) and is concise enough for a card. Both forms are derived
deterministically from `business.ts` in `scripts/print/print-facts.mjs`; a drift test fails the build
if the source sentence changes.

## Defects fixed (Stage 1 register)

| Defect | Fix |
| --- | --- |
| Crop marks offset by the bleed | Marks are drawn in page coordinates outside the trim; `scripts/print/verify-crop-marks.py` renders each bleed PDF and fails if a mark is inside the trim or missing outside |
| No TrimBox/BleedBox | `scripts/print/pdf-boxes.py` sets real boxes; `verify-print` checks them from the PDF |
| Printed die guide + ~1 mm hole clearance | Die line removed from artwork; separate `door-hanger-die-guide.pdf`; layout tests enforce ≥0.25 in clearance below the hole |
| Unscaled QR captions | Per-piece caption minimums in the manifest, measured in a real browser by `verify-print` |
| Poster/board mechanically scaled | Each variant has a distinct large-format composition |
| Service-area drift | Derived + drift-checked (above) |
| Crest/wordmark duplication | `src/config/brand.ts` shared by `Logo.astro` and the print system; `print-facts` fails if the site stops using it |
| QR verifier duplication | `scripts/print/qr-map.mjs` resolves every QR through `marketing-links.ts`; the verifier decodes the generated PNGs and compares byte-for-byte |

## Route ordering decision (evidence)

A strict street-block-first ordering was implemented and measured on the real 4,241 stops: it
guaranteed **zero** street re-entries but raised the total straight-line distance from ~99 mi to
~145 mi with 90 long edges. That is worse field practice, so the shipped engine uses distance-first
NN + 2-opt with a strong same-street preference and an efficiency-bounded street-completion pass.
See `ROUTE-PLANNING.md` for the benchmark.

## Rejected / not shipped

- Discounts, guarantees, review counts, insurance/licensing claims (no owner approval).
- The Grok reference card's green/navy palette and wrong contact details (see the brand audit).
- Strict street-block ordering (evidence above).
- Any QR payload edited by hand (registry only).

## Change control

1. Facts → `src/config/business.ts`; mark → `src/config/brand.ts`; links → `src/config/marketing-links.ts`.
2. Piece/variant/mix → `scripts/print/manifest.mjs`.
3. Rebuild: `npm run print:build`; verify: `npm run print:verify`; masters: `npm run print:pptx`.
4. Regenerate this system's manifest doc: `node scripts/print/write-manifest-doc.mjs`.
5. Never print a build that fails verification.
