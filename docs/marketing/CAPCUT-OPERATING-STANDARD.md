## 5. CapCut workflow (mapped to the production topics)

1. **Project creation:** vertical `1080×1920` 30 fps for everything short-form; create a separate
   16:9 project when a longer cut needs it. Set 2K/4K **before** editing if a 4K export is ever
   needed (A).
2. **Importing iPhone media:** Media > Import; standard (non-HDR) capture recommended; HEVC/HDR
   import on Windows is **unverified** — test one clip first.
3. **Proxy/performance:** Proxy ON for 4K, hardware acceleration ON (A); close browsers while
   exporting (16 GB RAM machine — recommended setup).
4. **Timeline organization:** dialogue/hero track 1, b-roll above, music bottom; Main Track Magnet
   (A); split (Ctrl+B reported) + trim; keep a clean "before" and matching "after" for every
   transformation.
5. **Footage selection:** hook frame first (dirty→clean contrast or motion); discard unusable takes
   honestly; never re-stage dirt.
6. **Dialogue editing:** transcript-based editing (A) for commentary/VO; keep Hayli's natural voice
   conversational, not scripted-robotic.
7. **Rough cut:** hook (0–2 s) → setup (2–5 s) → demonstration (5–25 s) → result hold → CTA
   (Sheet 2 order); ~20–45 s typical.
8. **Keyframes:** slow zooms, parallax on stills, animated callouts (A).
9. **Speed ramps:** Speed > Curve custom (A) — gentle on cleaning motion ("keep the motion
   visible and satisfying rather than frenetic"); do not ramp the reveal hold.
10. **Slow motion:** 60 fps capture for reveal holds; optical flow (A) where available.
11. **Motion blur:** Motion Blur (Lens) on fast wipes/scrubs only, moderate intensity (A).
12. **Transitions:** mostly hard cuts; wipe/spray transitions and the Before & After style for
    reveals (C); never transition over the money shot.
13. **Effects and adjustment controls:** adjustment layer for a consistent grade (A); sparing use.
14. **Color correction:** match before/after frames honestly — same angle, same light; Adjust basics
    + curves/HSL (A).
15. **Filters:** prefer saved custom "clean luxury" look over browsing (names are B/C).
16. **Text and graphics:** large one-idea captions; import brand fonts (local import — A).
17. **Animated captions / auto captions:** Text > Auto Captions (A) → correct → Style tab (A);
    word-level animation caveated — verify on this build.
18. **Sound effects:** Audio > Sound effects (first use downloads; connection required); keywords in
    the library.
19. **Music editing / beat sync:** beat detection markers on the track (A); cut wipes/scrubs to the
    four-on-the-floor; funky cleaning playlist culture is the reference, not a CapCut feature.
20. **Volume automation:** volume keyframes for ducking (A; auto-ducking unverified).
21. **Dialogue cleanup:** Reduce noise + Enhance voice (A) on Hayli's VO; light touch.
22. **Audio mixing:** loudness normalize + fades (A); EQ/compressor unverified on desktop.
23. **Voice effects:** Voice changer (A) for comedy characters only.
24. **Layering and masking:** circle/rectangle/linear masks (A), blend modes/opacity (A), chroma
    key/Auto removal (A) for split screens and cutouts.
25. **Export formats:** MP4 H.264, 1080×1920 @ ~10–14 Mbps; optional 16:9 1080p for Facebook/YouTube
    when those land; caption burn-in for short-form.
26. **Vertical and horizontal projects:** vertical is primary; make a 16:9 project only when a
    platform or embed needs it.
27. **Archiving and reuse:** export MP4 is durable (assets can be delisted); archive the draft
    folder; reuse caption/text presets instead of rebuilding.
